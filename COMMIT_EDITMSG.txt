fix: "+ New project" button now visible on desktop projects page

USER REPORT: 'also i dont see a link to add a new porject any
where, in dashboard it says it when i click it it takes me
to porjects but then there is no link to add a new porject'

ROOT CAUSE

The projects page had two separate header blocks:
  1. DESKTOP (`hidden md:flex` / `hidden md:block`):
     - The project count badge
     - The big tagline heading
     - The description paragraph
     - NO action button. The only way to start a new
       project from desktop was via the empty-state
       "No projects yet" card, which disappeared as soon
       as the workspace had one project.
  2. MOBILE (`md:hidden`):
     - The title
     - A "+ New" link to /projects/new

So once you had at least one project, the only way to
create a new one was to:
  - Resize your window to mobile width
  - OR delete all your projects to reach the empty state
  - OR navigate to the URL by hand

Both are bad UX. The mobile "+ New" was always there
because the mobile header is a single-row bar with
title + action, and the action was naturally placed
in the unused space. The desktop header is a tall
hero-style block that just... forgot to include an
action.

FIX

Re-laid out the desktop header as a two-column flex:

  ┌─────────────────────────────────────┐
  │ [5] Projects                  [+ New │
  │ The build, end to end.        project]│
  │ Each project is a budget, ...         │
  └─────────────────────────────────────┘

  - Left column: project count badge, tagline,
    description (unchanged content)
  - Right column: + New project button (the one
    that was already in the mobile bar)
  - The badge count is now dynamic
    (`{projects.length}`) instead of hard-coded "5"
  - The badge color stays the same (orange) but
    the badge now shows the real count, which
    also makes the heading line shorter when
    projects > 9 (5 was hardcoded before)

The mobile header below stays as-is. The same
link to /projects/new is used so the page route
itself didn't change.

VERIFICATION

  - TypeScript clean
  - 284/284 tests passing
  - On deploy: projects page header on desktop now
    shows the orange "+ New project" button at the
    top right of the hero block, always visible
    regardless of how many projects exist
