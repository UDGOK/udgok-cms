// Recommendation #1 — proposed structure

ProjectPhotosClient → 8 focused files

Each component becomes a standalone file with its own test, lazy-loadable from a barrel.

Current

1,733 LOC14 components1 test file
  • Single client bundle for the whole feature
  • Can't lazy-load the lightbox / editor
  • Every edit re-runs the entire test suite
  • Components deeply nested, hard to follow

After

~ 250 LOC main8 small files8 test files
  • Main file imports & composes the pieces
  • Lightbox + editor can dynamic() import
  • Each component tested in isolation
  • One file = one responsibility
